## چه وقت استفاده شود

- کاربر می‌خواهد مدل زبانی به دادهٔ خودش (اسناد، دیتابیس، سایت) پاسخ بدهد نه فقط به دانش آموزشی‌اش.
- عبارت‌هایی مثل «چت با PDF»، «جست‌وجوی معنایی»، «knowledge base برای چت‌بات»، «کاهش hallucination با منبع».
- برای وقتی که fine-tuning زیادی است ولی prompt خام هم کافی نیست.

## روش

۱. **تکه‌بندی (chunking).** اسناد را به قطعات ۳۰۰ تا ۸۰۰ توکنی ببر، با ۱۰ تا ۱۵٪ همپوشانی بین قطعات پشت‌سرهم تا جمله‌ها نصف نشوند. مرز قطعه را روی پاراگراف یا سرتیتر بگذار، نه وسط جمله.

۲. **Embedding.** هر قطعه را با یک مدل embedding به بردار تبدیل کن. برای فارسی مدل چندزبانه لازم است (مثل خانوادهٔ `bge-m3` یا `multilingual-e5`). همان مدل را برای query هم استفاده کن.

۳. **ذخیره.** بردارها + متن قطعه + متادیتا (منبع، شمارهٔ صفحه، تاریخ) را در یک vector store بریز (Vectorize، pgvector، Qdrant، …).

۴. **بازیابی.** query کاربر را embed کن، `k` قطعهٔ نزدیک را بگیر (شروع با `k=5`). اگر نتایج نویزی بود، یک مرحلهٔ rerank اضافه کن.

۵. **ساخت prompt.** قطعات بازیابی‌شده را با جداکنندهٔ واضح در prompt بگذار و به مدل بگو فقط بر اساس همان‌ها جواب بدهد و اگر جواب در متن نبود بگوید «نمی‌دانم». منبع هر ادعا را ذکر کند.

## مثال

```
[context]
منبع ۱ (راهنما.pdf، ص ۴): سقف آپلود فایل ۱۰ مگابایت است.
منبع ۲ (faq.md): فرمت‌های مجاز png و jpg هستند.
[/context]

سؤال کاربر: چه فایل‌هایی می‌توانم آپلود کنم؟

دستور: فقط از [context] استفاده کن. اگر نبود بگو «نمی‌دانم». منبع را ذکر کن.
```

خروجی مطلوب: «png و jpg تا سقف ۱۰ مگابایت (منبع ۱ و ۲).»

## خطاهای رایج

- **قطعه‌های خیلی بزرگ** → بازیابی بی‌دقت و prompt پر از متن نامربوط. کوچک‌تر کن.
- **مدل embedding تک‌زبانهٔ انگلیسی روی متن فارسی** → شباهت‌ها بی‌معنی. مدل چندزبانه.
- **query و اسناد با دو مدل embedding مختلف** → فضای برداری ناهمخوان. یک مدل برای هر دو.
- **نگفتن «اگر نبود بگو نمی‌دانم»** → مدل از دانش خودش پر می‌کند و منبع جعل می‌شود.
- **بی‌توجهی به متادیتا** → نمی‌شود منبع را به کاربر نشان داد یا نتایج قدیمی را فیلتر کرد.

## بررسی نتیجه

- برای ۱۰ سؤال نمونه که جوابشان در اسناد هست، آیا قطعهٔ درست در `k` تای اول بازیابی می‌شود؟
- برای سؤالی که جوابش در اسناد **نیست**، آیا مدل «نمی‌دانم» می‌گوید یا از خودش می‌سازد؟
- آیا هر جواب منبع قابل‌ردیابی دارد؟
